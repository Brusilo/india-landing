# Обновление цен каждые 3 часа и курса ЦБ / Three-hour price refresh

## Поиск минимальной цены без внутреннего API

Если секрет `TUTU_PRICE_FEED_URL` не задан, GitHub Actions запускает обычный
браузер Chromium для публичного поиска Туту. Проверяет **14 маршрутов и
13 конкретных отелей** по адресам из `scripts/price-targets.json`:

* поезд: билет в одну сторону на **завтра по Москве**, **один взрослый**,
  минимальный доступный билет, а не цена распроданного вагона;
* авиабилет: **Москва — Дели**, завтра, один взрослый, эконом,
  минимальная цена доступного перелёта (условия багажа проверяйте при выборе);
* отель: **заезд завтра, выезд послезавтра, 1 номер / 1 взрослый**,
  минимальная цена доступного варианта размещения, а не стоимость завтрака,
  парковки или зачёркнутый старый тариф.

Важное ограничение: **скрипт не объявляет SEO-цены без дат актуальными**.
Учитываются только предложения, реально показанные в поиске на выбранную
дату; отсутствие номера, мест или ответа сайта не преобразуется в цену
«от». В этом случае у конкретной карточки остаётся примерная цена из
исходного макета. Точная стоимость может измениться до оформления.

После сбора скрипт передаёт JSON с базовыми рублёвыми ценами в
`scripts/update-market-data.py`. Тот же процесс получает курс ЦБ, а
браузерный код применяет промокоды **после** получения минимальной цены.
Условия промокода и итоговая цена подлежат подтверждению на Туту при покупке.

Публичный поиск не гарантирует 100% покрытия: сайт может не загрузиться,
изменить разметку или потребовать проверку пользователя. Скрипт не обходит
CAPTCHA, блокировки и авторизацию. Проверьте допустимость регулярного
автоматического обращения к сайту с владельцами сервиса. В логах GitHub
Actions видны `FOUND r1: ...` или `SKIP r1` для каждой карточки.

Проверка:
```bash
python scripts/scrape-public-prices.py --self-test
python scripts/scrape-public-prices.py --only r1,r2,h1 --out /tmp/tutu-test-prices.json
```

## Что уже работает

* `.github/workflows/update-market-data.yml` запускает проверку **каждые 3 часа**
  по cron `0 */3 * * *` (UTC: 00:00, 03:00, …, 21:00;
  Москва: **03:00, 06:00, …, 00:00** без сезонного перевода часов),
  а также вручную через **Actions → Update India landing FX and verified
  prices → Run workflow**. Запуск GitHub по расписанию может задерживаться.
  Каждый запуск заново проверяет минимальные предложения на завтра и курс ЦБ.
  Сам ЦБ может публиковать новый курс реже, чем обновляются цены.
* `scripts/update-market-data.py` получает официальный курс INR/RUB из
  `https://www.cbr.ru/scripts/XML_daily.asp`. Если ЦБ недоступен, используются
  данные зеркала `https://www.cbr-xml-daily.ru/daily_json.js`. Проверяется
  дата котировки и разумность значения. На выходных сохраняется последняя
  опубликованная банковская котировка, дата источника указывается явно.
* Пересчёт ₽ → ₹ общий для всех трёх языков. При ошибке обновления старая
  проверенная котировка остаётся в GitHub; задача падает с ошибкой, но курс
  не выдумывается.
* При наличии достоверной цены в источнике используется базовая цена
  поставщика. При отсутствии достоверной цены показывается исходная
  **примерная** цена карточки (не выдаётся за сегодняшнюю котировку).
* В карточках автоматически применяются описанные на лендинге промокоды:
  `INTAVIATUTU` — 15%, максимум 1000 ₽ на авиабилеты;
  `INTHOTELTUTU` — 15%, максимум 3000 ₽ на отели.
  У обоих промокодов срок до 31.12.2026 включительно.
  С 01.01.2027 программный расчёт скидки прекращается.
  Промокоды применяются покупателем при оформлении заказа; итоговое
  подтверждение скидки — на сайте Туту.

## Дополнительно: собственный проверенный тарифный источник

Собственный API/экспорт не обязателен для публичного поиска. Но если
потребуется более надёжное обновление всего каталога, можно предоставить
проверенный тарифный источник: он имеет приоритет над браузерным парсером
(не меняя дизайн и формулы скидок).

Подключите проверенный внутренний/API источник через **Settings → Secrets and
variables → Actions → New repository secret**:

* `TUTU_PRICE_FEED_URL` — HTTPS URL, возвращающий JSON с базовыми ценами
  без промокодов; обязательный для автоматического обновления карточек.
* `TUTU_PRICE_FEED_TOKEN` — *необязательный* Bearer-токен для этого API.
  Никогда не добавляйте токен в файлы сайта или Git-коммиты.

Формат ответа API:

```json
{
  "quote_date": "2026-10-12",
  "currency": "RUB",
  "source": "tutu-booking-api",
  "routes": {
    "r1": 1200,
    "r2": 19668
  },
  "hotels": {
    "h1": 5931,
    "h2": 3800
  }
}
```

Значения только числовые, целые рубли, **до скидки**. Запрос
`quote_date` — **завтра по Москве**: маршрутные карточки открывают
поиск билетов на завтра для одного взрослого, гостиницы — 1 номер/1 ночь
(заезд завтра, выезд послезавтра) для одного взрослого. Источник должен
рассчитывать цену на тех же условиях. Используйте ID карточек `r1..r14`
и `h1..h13`, не заголовки: переводы RU/EN/HI отличаются.

Фид может присылать частичные обновления: отсутствующие ID не обновляются.
Если дата другая, валюта не RUB или данные недостоверны, сборка завершается
с ошибкой без подмены цен. Браузер повторно проверяет дату котировки и
не применяет данные за вчера к завтрашнему поиску.

В GitHub Pages результат хранится в `assets/daily-prices.js`.
Это **общий файл** для RU, EN и HI. При обновлении GitHub Actions
коммитит файл и запускает обычный Pages-деплой. Публикация и
кеширование могут занять несколько минут.

## Проверка

```bash
python scripts/update-market-data.py --self-test
node tests/landing-pricing.cjs
node tests/landing-tours.cjs
```

Чтобы запустить обновление вручную, откройте GitHub Actions → указанное
расписание → Run workflow. В логах видны дата курса, источник и количество
обновлённых маршрутов и отелей; секреты в логах не выводятся.
